# 公开材料与省略范围

| 材料 | 公开方式 | 保留的核验能力 |
| --- | --- | --- |
| 当前安装脚本 | 与结论直接相关的未经修改片段 | 完整父文件哈希、字节数、三种坐标、精确提取选择器 |
| 完整安装来源 | 用 `$IMA_PROFILE` 相对路径表示 | 扩展 ID、版本和文件名；本机用户名未写入 manifest |
| 本地断网实验 | 原始假 Key、构造 Request、依赖替身、检查结果 | 可离线重跑，不依赖私有账号 |
| Magpie 真实调用 | 保留诊断请求、模型名、状态、简短回复和用量 | 网关凭据未收录；只使用非敏感诊断文本 |
| 用户截图 | 原始上传图片，Key 在图中为掩码 | 配置内容和 UI 报错；不构成网络记录 |
| 主程序签名检查 | 命令、退出码、证书主体、程序哈希与输出 | 仅认证主程序签名，不扩大至 profile 扩展 |
| 真实客户端网络捕获 | 目标请求元数据、实际 JSON、仅含假 Key 请求及 code/msg 响应的 DATA 帧 | 原日志哈希、索引、source/job/session/socket/stream 关联、帧字节和可重跑的提取程序；原件保留本地 |
| 同次日志/遥测上报 | 只选取描述该失败请求的日志字段 | `param` 和 `data` 原字符串与实际请求/响应匹配；完整遥测 body、身份字段、请求头和其他日志省略 |
| 新采集截图 | 只裁出配置表单与错误提示 | 原始私有截图哈希、裁剪坐标和公开 PNG 哈希；未生成或修补像素，周围知识库内容未公开 |

未公开账号 cookie、登录票据、真实 API Key、Magpie 上游凭据、知识库内容、私人聊天、完整浏览记录或原始敏感 NetLog。

公开片段没有对变量或字符串值做脱敏替换；它们本身不包含本次用户账号的动态凭据。相较原始研究目录，仓库只收录与当前结论相关的片段、回执和说明。完整应用包和不相关分析图没有上传。

本仓库未对供应商发送安全通知，未创建公开漏洞指控或代用户联系他人。
